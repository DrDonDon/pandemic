# Dead Ends

This is a first-class research artifact, not a bin.
A disproved conjecture or failed approach often contains the real result.

---

## Template entry

```
## [DATE] — [CONJECTURE ID or APPROACH NAME]

**Statement / approach:**
What was tried. Be precise enough that you wouldn't try it again.

**Why it failed:**
The step where it breaks down, or the counterexample.

**Counterexample (if applicable):**
Explicit construction or numerical witness.

**What it tells us:**
What constraint does this failure reveal? Does it narrow the problem?
Does the counterexample suggest a corrected conjecture?

**Related to:** [list any conjectures or approaches this touches]
```
